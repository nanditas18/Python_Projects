# Python Mini-Projects

A collection of lightweight, practical, and fun Python projects designed to practice core programming logic, algorithms, and automation. Whether you're a beginner starting out or looking for quick reference code, you'll find clean and well-documented scripts here!

---

## Project Directory

| Project | Description | Key Concepts |
| :--- | :--- | :--- |
| **[Guess the Number](./Number_Guessing_Game)** | A fun command-line Python game where the computer selects a random secret number, and the player tries to guess it within a limited number of attempts. | Loops, Conditionals, 'random' module |
| **[Guess the Word](./Word_Guessing_Game)** | A command-line Python word guessing game where players have five attempts to correctly guess a randomly selected secret word from a predefined list. | Loops, Conditionals, and the 'random' module. |
| **[Hangman](./Hangman)** | A classic command-line word guessing game where players uncover a hidden 5-letter word letter by letter before running out of chances. | Loops, Conditionals, Lists, String Manipulation, 'random' module |
| **[21 Game](./Lose_If_You_Say_21)** | A classic strategic counting game built in Python where you and the computer take turns counting up to 21. The player who is forced to say "21" loses the game! | Loops, Conditionals, Exception Handling, Lists. |
| **[Rock Paper Scissor](./Rock_Paper_Scissor)** | A classic command-line implementation of Rock, Paper, Scissors where the player competes against a computer opponent with score tracking. | Loops, Conditionals, 'random' module |
| **[2048 Game](./2048_Game)** | A command-line version of the classic 2048 puzzle game where players slide and merge numbered tiles on a 4x4 grid to reach the 2048 tile. | Matrices, Loops, Conditionals, Functions, 'random' module |
